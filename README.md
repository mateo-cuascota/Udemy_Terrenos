# Proyecto de Escena 3D en Unity - Arena y Terreno

Este repositorio contiene la tarea práctica desarrollada en **Unity**, cuyo objetivo principal es la creación de un entorno virtual interactivo mediante el diseño de topografía de terreno, colocación de vegetación y estructuración de escenarios con primitivas.

## 📌 Características de la Escena
- **Modelado de Terreno:** Sculpting de montañas y elevaciones naturales aplicando texturas y capas de vegetación sobre el suelo.
- **Vegetación:** Distribución de árboles a lo largo de las pendientes del mapa.
- **Arena de Combate:** Una plataforma central construida mediante la disposición y escala geométrica de bloques (cubos) con materiales personalizados.
- **Cámara:** Configuración y alineación de la Main Camera para capturar una perspectiva cinematográfica y limpia del entorno.

## 🛠️ Cómo Ejecutar el Proyecto
1. Clona o descarga este repositorio en tu computadora.
2. Abre **Unity Hub** y haz clic en **Add project from disk**.
3. Selecciona la carpeta raíz de este repositorio.
4. Una vez abierto en Unity, dirígete a la ventana **Project** y localiza la escena principal en la ruta correspondiente (`Assets/Scenes/...`).
5. Presiona el botón **Play ▶️** para visualizar la escena en ejecución o explora libremente desde la pestaña *Scene*.
